# Goosker-s-Mantle
A simple mod that adds mantling.

This mod adds a simple mantle mechanic that behaves similarly to Hytale's mantle mechanic, including an adjustable height range, sound effect, basic animation, and compatibility with common animation mods

The config file for this mod is titled: gooskers-mantle.json

Here is the default config:

```
{
  "config_version": 2,
  "minimum_mantle_height": 1.1,
  "maximum_mantle_height": 2.0,
  "cooldown_ticks": 30,
  "upward_velocity": 0.4,
  "detection_reach": 0.45,
  "animation_ticks": 14
}
```


Built-in Compatibility:
- Not Enough Animations
- First-person Model
