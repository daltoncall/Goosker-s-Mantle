# Credits

Goosker's Mantle was designed as a focused replacement for the ledge-grab
feature in Kestalkayden's Enhanced Movement. The referenced Enhanced Movement
1.0.6 jar identifies its bundled code and assets as CC0 1.0 Universal.

The implementation in this repository was written independently for Fabric
1.20.1. It does not bundle Enhanced Movement's classes or assets.

The original mantle sound effect was supplied by Gosker, LLC and converted to
Minecraft's mono Vorbis OGG format for this mod.
